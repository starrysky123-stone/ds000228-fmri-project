# ds000228-fmri-project

This repository is a project skeleton for the Brainhack School Project Management exercise.

## Project description

This project is based on the OpenNeuro dataset ds000228. The dataset contains MRI/fMRI data from children and adults during viewing of a short animated film.

The goal of this repository is to practice project management, reproducible research organization, version control, and environment sharing.

## Repository structure

- `data/`: data files or instructions for obtaining data
- `docs/`: project notes and documentation
- `results/`: analysis outputs and figures
- `scripts/`: scripts used to run analyses
- `src/`: source code for reusable functions
- `tests/`: test files for checking code
- `code/`: additional analysis code or notebooks

## Environment

The conda environment is described in `environment.yml`.

To recreate the environment, run:

```bash
conda env create -f environment.yml
conda activate ds000228-fmri-project
```

## Data

The dataset used for this project is OpenNeuro ds000228.

Dataset link: https://openneuro.org/datasets/ds000228
